## Course Overview

Web development has changed. In 2026, developers don't write every line by hand — they work *with* AI tools to build faster, ship faster, and focus on what actually matters: solving real problems for real users.

This course teaches you to build complete, live websites using AI coding assistants and no-code/low-code AI builders — while still giving you enough technical literacy to understand, customize, and fix what AI generates. You won't just prompt blindly; you'll learn to direct AI like a professional developer does.

**Perfect for:** Students exploring tech careers, working professionals wanting to build fast, freelancers wanting a high-leverage modern skill, and business owners who want to build or update their own site without hiring a developer for every change.

## Curriculum

### Module 1: The Modern Web Developer's Workflow
- How web development actually works in 2026 — AI-assisted, not AI-replaced
- Overview of the AI dev stack: AI coding assistants, AI website builders, deployment platforms
- Setting up your toolkit (browser, code editor, AI tools accounts)

### Module 2: Web Fundamentals (Just Enough to Be Dangerous)
- How websites work: HTML structure, CSS styling, JavaScript behavior — explained practically
- Reading and understanding AI-generated code (not writing from scratch, but knowing what you're looking at)
- Why fundamentals still matter even when AI writes the first draft

### Module 3: Building with AI Coding Assistants
- Prompting effectively for web development (specific, structured prompts vs. vague ones)
- Hands-on with modern AI coding tools (e.g. Claude, Cursor, similar assistants)
- Iterating: fixing, refining, and customizing AI-generated code

### Module 4: AI Website Builders & Rapid Prototyping
- Using AI-first builders (e.g. v0, Lovable, Bolt, Framer AI — whichever tools trainer selects)
- Going from idea → working prototype in minutes, not weeks
- When to use a builder vs. when to hand-code a section

### Module 5: Styling & Making It Look Professional
- Design fundamentals: layout, spacing, color, typography (AI needs direction here too)
- Using Tailwind CSS with AI assistance for clean, responsive design
- Making sites look custom, not template-generic

### Module 6: Connecting Real Functionality
- Forms, contact submissions, basic backend concepts (using AI to scaffold this)
- Introduction to databases and APIs at a beginner level (e.g. Supabase basics)
- Understanding what's happening "under the hood" even when AI builds it

### Module 7: Deployment & Going Live
- Git/GitHub basics for version control
- Deploying with Vercel/Netlify
- Custom domains and going live for real

### Module 8: Capstone Project
- Plan and build a complete website/web app using your AI-assisted workflow
- Deploy it live with a working URL
- Present it for trainer feedback — portfolio and interview-ready

## FAQs

**Q: If AI builds the website, what am I actually learning?**
You're learning to direct AI effectively, understand and customize what it generates, and combine tools professionally — this is exactly how working developers operate today. Pure prompting without understanding gets you stuck the moment something breaks; this course prevents that.

**Q: Do I still need to learn to code?**
You'll learn enough HTML/CSS/JS to read, understand, and fix code — but you won't be writing everything from scratch the old way. That's the point: work smarter, ship faster.

**Q: I have zero coding background. Can I still join?**
Yes — this course is designed for complete beginners and builds up step by step.

**Q: Will I build a real, live website?**
Yes — multiple projects throughout the course, ending with a live, deployed capstone project.

**Q: What if I miss a live session?**
Recordings are provided so you can catch up before the next class.

**Q: Is there a certificate?**
Yes, a Celoris certificate of completion is provided at the end.
