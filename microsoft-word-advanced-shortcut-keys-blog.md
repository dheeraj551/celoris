## FAQs

**Q1. Do these shortcuts work on all versions of Microsoft Word?**
Most shortcuts work on Word 2010, 2013, 2016, 2019, 2021, and Microsoft 365. Some ribbon-based shortcuts (Alt + N, etc.) may vary slightly by version.

**Q2. Do Word shortcuts work on Mac?**
Mac uses `Command (⌘)` instead of `Ctrl` for most shortcuts. For example, `Ctrl + B` on Windows = `⌘ + B` on Mac. Some advanced shortcuts differ more significantly.

**Q3. How do I find shortcuts I've forgotten?**
Press `Alt` in any Word window to activate ribbon key tips — letters will appear over each ribbon tab showing you the keyboard navigation path.

**Q4. Can I create custom keyboard shortcuts in Word?**
Yes. Go to **File > Options > Customize Ribbon > Keyboard Shortcuts: Customize** to assign your own shortcuts to any Word command.

**Q5. What is the fastest way to open Word's Find & Replace?**
`Ctrl + H` opens Find and Replace directly. `Ctrl + F` opens just the Find sidebar.
