What was actually run: 12 distinct queries built from the brief's services (course discovery, pricing, location/"near me", job-outcome, and course-type comparisons), each sent live to ChatGPT (gpt-5-mini) and Perplexity (sonar-pro) with web search enabled — 24 attempts total. 2 ChatGPT attempts did not trigger a web search (the model asked a clarifying question or answered from training data instead) and were excluded from the citation tally as invalid data points, leaving 22 valid live checks, all zero citations for this domain. Gemini and Claude were not live-tested this run — the DataForSEO AI Optimization toolset used here covers ChatGPT and Perplexity live spot-checks directly; that is a real coverage gap in this report, not a finding that those engines are clean. Cross-check: the aggregated historical LLM-mentions dataset (real indexed AI conversations, not a live check) was also queried. For India, that dataset only has volume on platform="google" (AI Mode) — the chat_gpt platform in that same dataset is populated for the United States only, not India — so it was used for a broader India/Google AI Mode confirmation, not as a second engine in the main table. It returned zero recorded mentions of celorisdesigns.com; a broad control query ("digital marketing course", no location) was run against the same dataset first and returned thousands of real mentions with a real domain breakdown, confirming the zero result is a real gap and not a broken or misused endpoint. The same dataset had no recorded volume at all for the hyper-local query "digital marketing course noida" — that's a genuine data-thin spot in the dataset, not evidence either way, and is exactly the kind of query this report recommends seeding back into keyword-fanout-map. Competitor table: tabulated from 21 of the 22 valid checks — one Perplexity query (course-syllabus topics) was dropped from the automated domain-frequency tally by a script oversight. Its raw response was checked by hand and also cited zero mentions of celorisdesigns.com, consistent with every other check, so this doesn't change any number in the "you" row or any conclusion — only the exact denominator, which is why the table below is described as 21 tabulated checks rather than 22. Brand-mention tracking: this run tallied cited domains (a link/citation), which is the strict, defensible signal. It did not separately track the softer case of the brand name "Celoris" being said without a link — no response text spotted while reading results named it that way either, but that was not systematically logged, so "0 unlinked mentions" would be an overclaim. Treat that line as unmeasured, not as a second confirmed zero. One structural gap below (placement/job-guarantee queries) is flagged fail on purpose: competing there would require guaranteed-placement language, which the brief's own hard content rules prohibit. That's a deliberate trade-off, not a content shortcoming to fix.
